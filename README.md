# Biggest heading BERT Fine-Tuning for Sentence Classification


This project fine-tunes a pretrained BERT model using Hugging Face Transformers to determine whether two sentences have the same meaning (MRPC dataset).

The model is trained and evaluated using accuracy and F1 scores, then compared with BERT before fine-tuning.
